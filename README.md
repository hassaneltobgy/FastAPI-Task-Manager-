# FastAPI-Task-Manager-
Built a RESTful Task Management API using FastAPI with full CRUD operations. Implemented Pydantic models for data validation, UUID-based task IDs, and proper HTTP error handling. Used in-memory storage to simulate backend logic and deployed via Uvicorn with Cloudflare tunneling for public access.
